# Proposals and Governance

The Proposals surface at `/proposals` is the governance workspace for reviewing and applying maintenance or agent-generated changes.

## What It Does

- Presents pending proposals with evidence and risk metadata.
- Shows file diffs and contextual details before apply decisions.
- Supports review comments and traceable approval workflows.
- Maintains a topic map view for grouped change visibility.

## Why It Matters

This feature keeps write operations auditable and reviewable. It separates generation from application so AI-assisted changes stay controlled.

## Key Capabilities

- Proposal list with status and risk indicators.
- Diff-first review model for safer approvals.
- Topic map visualization for grouped changes.
- Integration path for maintenance tasks and chat agent proposals.
