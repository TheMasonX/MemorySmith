# Memories Workbench

The Memories Workbench is the structured memory surface at `/memories`. It is the primary place to manage memory records that power search, chat retrieval, context packs, and maintenance workflows.

## What It Does

- Browses memory records across status buckets.
- Creates and edits records with confidence, tags, references, conflicts, and source links.
- Runs lexical, semantic, and hybrid search from one interface.
- Supports filtered and ranked recall for both human use and agent tooling.

## Why It Matters

Structured memories are the backbone of MemorySmith. They carry metadata that markdown pages do not, including references, conflicts, and source links.

## Key Capabilities

- Status-aware records: Unconsolidated, Working, Core, Deprecated.
- Confidence and usage tracking for memory quality workflows.
- Source-link support with optional line ranges.
- Search and filtering optimized for operational knowledge reuse.
