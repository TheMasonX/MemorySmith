# Feature Guide By Persona

This page organizes major MemorySmith features by primary user role so people can find the right surface quickly.

## Viewer (Read-focused)

- [Memories Workbench](memories-workbench.md): browse and search structured memories.
- [Markdown Pages Wiki](markdown-pages-wiki.md): read wiki pages and narrative docs.
- [Search System](search-system.md): understand lexical, semantic, and hybrid retrieval.
- [Chat and Agent](chat-and-agent.md): ask questions and review trace/reference context.
- [Health and Diagnostics](health-and-diagnostics.md): check high-level system status.

## Editor (Content and Curation)

- Everything in Viewer scope, plus:
- [Memories Workbench](memories-workbench.md): create and edit memory records.
- [Markdown Pages Wiki](markdown-pages-wiki.md): create and edit markdown pages.
- [Variables and Source Links](variables-and-source-links.md): maintain source-link path variables for portable evidence links.

## Admin (Governance and Operations)

- Everything in Editor scope, plus:
- [Admin and Authentication](admin-and-auth.md): role, provider, settings, audit, and history controls.
- [Proposals and Governance](proposals-and-governance.md): review and apply proposal workflows.
- [API and MCP Integration](api-and-mcp.md): secure automation and tool surfaces.

## Automation And Agent Workflows

- [API and MCP Integration](api-and-mcp.md): machine-facing route and tool model.
- [Search System](search-system.md): retrieval behavior and quality expectations.
- [Chat and Agent](chat-and-agent.md): chat, tool loops, and proposal-gated write path.

## Walkability Tips

- Start at [Features Index](index.md) for broad orientation.
- Use [Feature Route Map](route-map.md) when you know a route and want the matching feature doc.
- Use [MemorySmith Pages](../guides/memorysmith.md) for deeper architecture and operations guidance.
